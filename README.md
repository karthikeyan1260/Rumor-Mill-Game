# 🎮 Rumor Mill Game – Python & Gradio

**Pass the message. Change the story. Become the Rumor Master!**

An interactive, turn-based message transformation game built using Python, Object-Oriented Programming (OOP), and Gradio. Players pass messages through human and rule-based AI players, creating unexpected changes along the way.

## 📌 Project Overview

The Rumor Mill Game simulates how messages change as they pass between multiple players. The final message is compared with the original to calculate accuracy and award points.

## 🎯 Features

- 👥 Support for 1–4 human players.
- 🤖 5–10 simulated AI players.
- 🎚️ Three difficulty levels: Easy, Medium, Hard.
- 🔄 Multiple game rounds (1–5).
- 📝 Automatic word replacement.
- 📊 Accuracy-based scoring system.
- 📜 Game history tracking.
- 🏆 Top 10 leaderboard.
- 💾 JSON-based score persistence.
- 🌐 Interactive Gradio interface.

## ⚙️ How It Works

1. Enter human player names.
2. Select the number of AI players.
3. Choose difficulty and game rounds.
4. Generate an original message.
5. Human and AI players modify the message.
6. Compare the final message with the original.
7. Calculate accuracy and scores.
8. Save the final score to the leaderboard.

**3. Open Jupyter Notebook**

**4. Run the notebook**

Open `Rumor Mill Game.ipynb` and execute all cells.

The Gradio application will launch with a local interface.
